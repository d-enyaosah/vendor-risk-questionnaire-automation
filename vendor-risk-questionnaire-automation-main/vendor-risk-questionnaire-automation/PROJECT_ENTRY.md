# Project

## Vendor Risk Questionnaire Automation 
- Build a Python workflow that normalizes vendor security-questionnaire responses, evaluates control severity, flags missing assurance evidence, and generates prioritized risk findings and remediation guidance.
- Automate the production of a structured risk-review CSV and stakeholder-ready HTML dashboard, demonstrating practical TPRM, evidence-review, risk-scoring, and reporting capabilities.
- Design a transparent rules-based model with repeatable test coverage and extensible inputs for future NIST, ISO 27001, SOC 2, GRC-platform, and ticketing integrations.
